# Results

Drop demo screenshots, captured logs, and run findings here for the writeup and
presentation. Suggested artifacts:

- `dashboard-light.png` / `dashboard-dark.png` — the live dashboard in both themes
- `run_demo.txt` — output of `python -m simulations.run_demo` (11/11 checks)
- `trace-r002.txt` — a `WeaknessReport.render()` source-trace report
- per-scenario alert exports from `/api/snapshot`

Files matching `*.local.*` are git-ignored, so you can keep scratch captures here
without committing them.
